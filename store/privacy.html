Sizer privacy policy

Effective 5 October 2026

Sizer is a Chrome extension that shows which clothing size to buy on product pages. It is built to work without collecting anything about you.

What Sizer stores

Your fit profile: the measurements you enter (including height and weight, if you add them), the clothes you add, how they fit and any flat-lay measurements you give them, your preferred units and your fit preferences. It is saved with Chrome’s own storage in your Chrome profile. If Chrome sync is on, Chrome keeps it in step across your devices, the same way it does for your other extension settings.

Your recent sizings: for each product Sizer sizes for you, the brand, the product title, the kind of item, the shop’s hostname, the sizes the page offered, the size Sizer suggested and the date, the last 50 from the last 60 days. Sizer keeps this list in your browser only (Chrome’s local storage, not synced), so it knows when to ask whether something fitted. Nothing in it leaves your browser except the answer you give, described below.

What Sizer reads

On supported shops, on Vinted item pages, and on any page where you click the Sizer icon and ask it to, Sizer reads the product page in your browser: the brand, the product details, the sizes and whether they’re in stock. This happens on your device. Nothing from the page is saved except the recent sizing above, and nothing is sent except what is described below: a review tally, a request for the pooled tally of the same style, the brand, item kind and size-guide table when a brand has no chart yet, the web address of a size chart image, the brand, style, item kind and review counts when Sizer asks what others say about the fit, only when you ask for it, the page’s product text or the web addresses of a Vinted listing’s photos, and, only when you answer “Did it fit?”, your answer.

What Sizer sends

Nothing about you. Your fit profile never leaves your browser. Once a day Sizer downloads the latest brand size charts, and the fit counts described below, from its own database (a Supabase project). Those requests carry no data from you or from the pages you visit: no profile, no page, no identifier, only the request for the lists, which is the same for everyone.

A few things do go the other way. When a product page has customer reviews, Sizer counts how many say the item runs small, runs large or fits true to size, and sends that tally to the same database, so that shoppers looking at the same style on another shop can use it. The tally carries the brand, the style name, the shop’s hostname and the counts. It does not carry your profile, the page address, the review text, or anything that identifies you. A random id generated at install, unrelated to you or your browser, lets a later read of the same page replace the earlier tally instead of adding to it. When Sizer sizes a product it also asks the database for the pooled tally of that style; that request carries only the brand and style name.

When a product’s brand has no size chart in the database yet, Sizer asks the database to look one up, so it can size you on the brand’s own chart instead of a generic one. That request carries the brand name, the kind of item (for example jeans or a dress), the shop’s hostname, the same random install id, and, when the page prints a size table in its size guide, the text of that table. It does not carry your profile, your measurements, the page address or anything else from the page. The database finds the brand’s published chart with an AI model (Anthropic’s Claude) and stores it for every shopper, marked as read by machine until a person checks it. If no chart is found, Sizer remembers that for a week and does not ask again for that brand and kind of item.

Before that lookup, when the product page prints no size table of its own, Sizer looks where else the shop keeps it. If the page links to the shop’s own size-guide page, Sizer opens that one page in the background, once per product page and without your cookies, and reads the table there. That request goes to the shop, not to Sizer, and nothing from it is kept. If the shop’s chart is an image, Sizer sends the image’s web address (a picture on the shop’s server, not the page address) to its database with the brand name, the kind of item and the same random install id. The database reads the chart from the image with Anthropic’s Claude, which fetches the image itself, and keeps what it read with the image’s web address, so the next shopper who meets the same image gets the answer without another read. What it read joins the lookup above as the shop’s size table, marked as read by machine.

When you click “Check this page anyway” and Sizer finds no brand or no sizes, the popup offers “Read this page with AI”. Only if you click it, Sizer sends the page title, the page’s headings and the text around the size picker (or around the product title when there is no picker), up to 6000 characters in all, with any web addresses taken out, and the same random install id. Anthropic’s Claude reads the brand, title, kind of item, sizes and fabric from that text and Sizer uses them to size the page. The text is not stored: the database keeps only the install id and the time, to hold each install to a daily limit.

Once Sizer has shown your size on a product page, it asks its database what others say about the fit of that item online, once per item, so it can refine the answer. That request carries the brand name, the style name, the kind of item (for example jeans or a dress), the shop’s hostname, the same random install id, and the anonymous review counts from the page: how many reviews say it runs small, runs large or fits true to size, and how many mention an area that is tight, loose, long or short, such as the hips or the leg. It does not carry your profile, your measurements, the page address or any review text. The database searches the web with Anthropic’s Claude for what retailer reviews and fit blogs say about that brand and style, keeps only sources a search really returned, and stores the result for every shopper for 30 days; the review counts reach the model only as context. Your browser keeps the answer for 30 days, or for 7 days when nothing was found, and does not ask again for that item in the meantime. Sizer decides on your device what the answer changes, and lists the pages it came from under the reasons.

On Vinted item pages (the 22 Vinted country sites, such as vinted.fr, vinted.de and vinted.co.uk), Sizer reads the listing in your browser: the brand, the size on the label, the category, the condition, the description and the photos. It compares any measurements the seller wrote with the pieces you own or your measurements on your device, and can write a short message asking the seller for the measurements that are missing. That message is only copied to your clipboard when you click “Ask the seller to measure”; Sizer never sends anything on Vinted. Only if you click “Read measurements from the photos”, Sizer sends the web addresses of up to four of the listing’s photos (pictures on Vinted’s servers, not the listing’s address), the kind of item (for example a dress or jeans) and the same random install id to its database, which asks Anthropic’s Claude to read any measurements the photos show. The photo addresses and what was read are not stored: the database keeps only the install id and the time, to hold each install to a daily limit. As on any shop, Sizer also asks for the pooled review tally of the same brand and style.

A week after Sizer sizes a product, or when you come back to its page, the popup, the side panel and the sheet on the page ask “Did it fit?”: did you buy it, which size, and was it too small, right or too big, with the areas where it did not fit if you want to say. You can answer, say you did not buy it, or ignore it. An answer is added to the pieces you own in your fit profile, in your browser, so your next sizes learn from it. Sizer also sends the answer to its database, anonymously: the brand and style name, the kind of item, the shop’s hostname, the size you bought, the size Sizer suggested, the verdict (too small, right or too big), the areas you picked, the chart tier (which kind of size chart the suggestion was read from) and the same random install id, which lets a second answer for the same item replace the first and holds each install to a daily limit. It never carries your measurements, your profile, the other pieces you own or the page address. The database adds these answers up per brand and kind of item, counting only answers where the size bought was the size Sizer suggested, and shares nothing but those counts, and only once ten answers are in, so no single purchase ever shows. Every Sizer user then gets that brand’s learned tendency, worded for example as “12 Sizer users who bought this brand say it runs small”, when the page, its reviews and what others say online about the item have not moved the size. If an answer cannot be sent, Sizer keeps it in your browser and tries again the next day.

Sizer has no accounts, no analytics and no advertising. It doesn’t sell, share or transfer any data, and it doesn’t use data for anything other than showing you and other shoppers their size; what other shoppers see is only the counts above.

Deleting your data

Remove the clothes and measurements on Sizer’s fit profile page, or uninstall the extension, which deletes everything it stored in your browser, recent sizings included. Answers already sent carry nothing that identifies you, so they cannot be traced back to you to delete.

Changes

If this policy changes, the new version will be posted here with a new effective date.
